## A hard-constrained physics-guided recurrent neural network for modeling the quench dynamics of 2G HTS coated conductors (2G HTS CC).
# Article link:

# Data for the quench dynamics of 2G HTS CC and CFD tapes with the corresponding code for each model presented in the article.

This repo as 2 folders:
1) Levin2D_quench_cooling_10ms: 2D 2G HTS CC tape with hastelloy, YBCO and Ag layer in quench and cooling conditions. Time scale of 10 ms. The data set is available for the 2D results presented in the article and its associated code are there.
2) Levin3D_CFD_10ms: 3D current flow diverter (CFD) tape. Same material sets as the 2D configuration. Only quench conditions, and time scale of 10 ms. The data set is available for the 3D results presented in article and its associated code. The data set is avaiable there.
